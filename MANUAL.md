# 📖 Руководство пользователя Delta

**Delta** — это профессиональный инструмент для построения, визуализации и анализа тройных диаграмм состояния (Треугольник Гиббса). Приложение позволяет работать с многокомпонентными системами, рассчитывать фазовые соотношения и строить коноды.

---

## 🖥️ Интерфейс

Главное окно программы разделено на две части:
1.  **Область графика (Слева):** Интерактивный треугольник Гиббса. Здесь отображаются точки, линии и сетка.
    *   Поддерживает масштабирование (Zoom) и перемещение (Pan) с помощью инструментов на панели сверху.
    *   Отображает координаты курсора в реальном времени.
2.  **Панель управления (Справа):** Содержит пять вкладок для работы с данными:
    *   `Compositions` — Таблица составов (точек).
    *   `Lines` — Управление линиями и расчет пересечений.
    *   `Analysis` — Расчет правила рычага и стехиометрии.
    *   `Region` — Ограничение видимой области диаграммы полигоном.
    *   `Annotations` — Текстовые аннотации с настройкой шрифта, рамки и стрелки.

---

## 🛠️ Основные функции

### 1. Работа с Составами (Compositions)
Перейдите на вкладку **Compositions**.

*   **Добавление точки:** Нажмите кнопку `Add New Composition`. В таблице появится новая строка с координатами, соответствующими центру текущего видимого региона диаграммы.
*   **Редактирование:**
    *   **Имя:** Дважды кликните по ячейке с именем (Name) для переименования.
    *   **Координаты:** Введите значения в столбцы компонентов (A, B, C).
*   **Настройка отображения:**
    *   Нажмите **Правой Кнопкой Мыши** (ПКМ) на строку в таблице.
    *   Выберите `Customize Marker...`, чтобы изменить цвет, форму (круг, квадрат, треугольник и др.) и размер точки.
    *   Там же можно включить/выключить подпись и сам маркер.
*   **Перемещение подписей:** Вы можете перетаскивать текстовые метки точек прямо на графике, зажав ЛКМ.
*   **Удаление:** ПКМ по строке -> `Delete Composition`.

### 2. Настройка диаграммы
В верхней части вкладки **Compositions**:
*   **Labels:** Введите названия компонентов (например, H2O, Oil, Surf) и нажмите `Update Names`.
*   **Inverted:** Переключает треугольник в перевернутый режим (вершина C внизу).
*   **Grid:** Включает/выключает сетку.
*   **Step:** Задает шаг сетки (например, 0.1 = 10%).

### 3. Работа с Линиями (Lines)
Перейдите на вкладку **Lines**.

*   **Создание прямой линии:** Нажмите `➕ Add Straight`.
    *   Выберите начальную (Start) и конечную (End) точку из списка.
    *   Настройте цвет, стиль (сплошная, пунктир), толщину и стрелку.
*   **Создание кривой линии:** Нажмите `〜 Add Curve`.
    *   Выберите начальную и конечную точку.
    *   Добавьте произвольное количество опорных (guide) точек — линия строится как сплайн через них.
*   **Редактирование:** Дважды кликните по линии в списке или выберите её и нажмите `✏️ Edit`.
*   **Удаление:** Выберите линию и нажмите `🗑️ Delete` или клавишу `Delete`.
*   **Контекстное меню:** Правый клик на линии в списке открывает быстрый доступ к Edit и Delete.

> В списке прямые линии отображаются с префиксом `───`, кривые — с `∿──`.

### 4. Ограничение области отображения (Region)
Перейдите на вкладку **Region**.

*   Добавьте минимум 3 точки, задающих замкнутый полигон.
*   Включите маску кнопкой **Enable** — всё за пределами полигона будет скрыто белой маской.
*   Диаграмма автоматически масштабируется под bounding box заданного контура.

### 5. Текстовые аннотации (Annotations)
Перейдите на вкладку **Annotations**.

*   **Добавление:** Нажмите `➕ Add`. Появится новая аннотация с настройками по умолчанию.
*   **Видимость:** Галочка слева в списке управляет отображением аннотации.
*   **Редактирование** (выберите аннотацию в списке):
    *   **Text** — текст подписи; `\n` для перевода строки; поддерживается MathText (`$Al_2O_3$`).
    *   **Position** — барицентрические координаты размещения текста; можно выбрать точку кликом на диаграмме (кнопка Pick).
    *   **Font** — размер, цвет, жирный/курсив, выравнивание по горизонтали и вертикали.
    *   **Background Box** — рамка с заливкой вокруг текста (цвет, прозрачность, отступ).
    *   **Arrow / Pointer** — стрелка от текста к целевой точке (целевые координаты тоже выбираются кликом).
*   **Удаление:** Выберите аннотацию и нажмите `🗑️ Remove`.

## 📐 Система Координат

Delta использует **мольные доли** (molar fractions) в качестве координат:

- Каждая координата — число от 0 до 1
- Сумма координат всегда равна 1 (автоматическая нормализация)
- Значения отображаются как доли (0.333) или проценты (33.3%)

> **Пример:** Состав с координатами A=1, B=2, C=3 будет нормализован до A=0.167, B=0.333, C=0.500

### Единицы измерения в интерфейсе

- **Таблица составов:** Координаты отображаются как мольные доли (например, 0.3333)
- **Координатный overlay:** Показывает "Molar fractions" с нормализацией (Σ=1)
- **Результаты анализа:** Отображаются в мольных процентах (mol.%) с пояснениями:
  - "Lever Rule (mol.%)" — для линейного анализа
  - "Basis Fractions (mol.%)" — для треугольного анализа
  - "Stoichiometry (molar ratio)" — для стехиометрии

### Подсказки (Tooltips)

- Наведите курсор на заголовки столбцов таблицы — увидите пояснение о мольных долях
- Наведите на координатный overlay — увидите пояснение о системе координат
- Наведите на поля ввода в Analysis Panel — увидите пояснение о нормализации

## 🧪 Анализ и Расчеты

### Правило Рычага (Lever Rule)
Перейдите на вкладку **Analysis**. Этот инструмент позволяет рассчитать доли фаз для любой точки.

1.  **Выбор режима (Basis Mode):**
    *   **Linear:** Расчет на прямой (между двумя точками).
    *   **Ternary:** Расчет внутри треугольника (между тремя точками).
2.  **Задание Базиса (Define Basis):** Выберите точки, образующие коноду (для Linear) или область (для Ternary).
3.  **Целевая точка (Target Point):**
    *   **Mouse Cursor:** Просто наведите мышь на график. Результат обновляется в реальном времени.
    *   **Existing Composition:** Выберите сохраненную точку из списка.
    *   **Manual Input:** Введите координаты A, B, C вручную.
4.  **Результат:**
    *   Показывает мольные доли компонентов базиса.
    *   **Stoichiometry:** Пытается подобрать целочисленные коэффициенты (например, 1:2, 2:3).

### Lever Mix — создание состава по правилу рычага

На вкладке **Analysis** нажмите кнопку `Lever Mix…`.

1.  Выберите два конечных члена (End A и End B) из списка составов.
2.  Задайте молярную долю B в поле **mol% of B** (0–100).
3.  Результирующий состав немедленно отображается на диаграмме в виде предварительного маркера.
4.  Настройте вид маркера (цвет, форма, размер) с помощью **Marker Style**.
5.  Нажмите `Add to Project`, чтобы сохранить точку в проект, или закройте диалог.

> Диалог немодальный — с ним можно работать, не закрывая основное окно.

### Поиск Пересечений (Intersection)
Находится на вкладке **Lines** -> кнопка `📐 Intersection Calculator`.

1.  Выберите две линии из списка (Line 1 и Line 2).
2.  Если линии пересекаются, программа покажет координаты точки.
3.  Нажмите `Add Intersection as Composition`, чтобы сохранить найденную точку в проект.
    *   *Галочка "Show Extrapolations"* позволяет найти пересечение, даже если физически отрезки не касаются друг друга (продлевает их до границ).

## 💾 Управление Проектом

В меню **File** доступны следующие действия:

*   **New Project** (`Ctrl+N`): Создает новый пустой проект (сброс к заводским настройкам).
*   **Save** (`Ctrl+S`): Сохраняет изменения в текущий файл.
*   **Save As...** (`Ctrl+Shift+S`): Сохраняет проект в новый файл `.json`.
*   **Load Project...** (`Ctrl+O`): Загружает ранее сохраненный проект.
*   **Export Image...** (`Ctrl+E`): Экспортирует текущий вид графика в форматы PNG, JPG, SVG или PDF. Идеально для публикаций.

> **Примечание:** Если в заголовке окна рядом с названием файла стоит звездочка `*`, значит в проекте есть несохраненные изменения.
